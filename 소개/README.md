# 집밥 타이밍 · 밥맞J

밥맞J는 운전자가 목적지로 이동하는 길에 음식을 주문하고, 식당이 관리하는 지정 픽업 구역에서 차에서 내리지 않고 음식을 받을 수 있도록 돕는 차량 픽업 서비스입니다. 차량 앱과 식당 웹은 같은 주문을 공유합니다. 운전자는 픽업 장소와 주문 상태를 확인하고, 식당은 도착 예정 시각에 맞춰 조리와 인도를 준비합니다.

## 설치와 시연 자료

| 자료 | 내용 |
|---|---|
| [차량용 서명된 릴리스 APK](./babmatj-automotive-release.apk) | 11월 13일 소스로 빌드하고 로컬 릴리스 키로 서명한 APK |
| [서비스 흐름도](./흐름도.md) | 차량 앱·중앙 서버·식당 웹의 주문, 예약, 인도 과정 |
| [단계별 화면 캡처](./flows/README.md) | 11월 12일 목적지 설정부터 양쪽 화면의 인도 완료까지 |
| [설치 및 로컬 시연 절차](../docs/api/two-screen-demo.md) | ADB 설치, 서버 연결, 시연 데이터 준비 |

로컬 주문 시연에는 [차량용 디버그 APK](./babmatj-automotive-debug.apk), Pleos Connect 에뮬레이터, 로컬 NestJS 서버와 DB, 차량 개발 계정 설정이 필요합니다. 현재 릴리스 앱의 주문 연결에는 별도 설정 방식이 필요합니다.

## 시연 영상

[밥맞J 전체 시연 영상 보기 또는 다운로드](./babmatj-pickup-demo.mp4)

11월 12일 Pleos Connect 에뮬레이터와 식당 웹에서 진행한 시연 화면 16장을 한국어 자막과 함께 편집했습니다. 영상 길이는 1분 24초입니다.

| 영상 구간 | 화면에서 확인할 내용 |
|---|---|
| 00:00–00:20 | 강남역 2호선을 목적지로 설정하고, 픽업 장소를 경유하는 총 주행거리를 비교해 한끼상회를 선택합니다. |
| 00:20–00:35 | 비빔밥 1개와 픽업 장소를 선택해 주문합니다. 차량과 식당 웹에 같은 주문이 접수 대기로 표시됩니다. |
| 00:35–00:57 | 식당이 조리시간과 모의 ETA를 입력해 주문을 수락합니다. 조리 시작 예정 시각과 픽업 예약 구간을 확인합니다. |
| 00:57–01:24 | 식당이 조리 시작, 준비 완료, 차량 입장, 음식 인도를 차례로 확인합니다. 양쪽 화면에 주문 완료가 표시되고 식당 화면에서 공간 반환을 확인합니다. |

## 시연 환경

목적지와 경유 거리는 Pleos 내비와 카카오 길찾기 응답으로 확인했습니다. 조리 일정과 도착 안내는 식당에서 입력한 모의 ETA를 사용했고, 입장과 인도는 식당 웹에서 수동으로 확인했습니다. 수락 직후 내비에 픽업 구역이 표시됐으며, 강남역을 최종 목적지로 유지한 경유지 확정은 미검증입니다.
